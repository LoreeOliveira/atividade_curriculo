## 💡 Como a Lorena Oliveira Fez Este Projeto? (Bastidores 🎬)

Olá! Eu sou a **Lorena Oliveira** e criar este currículo não foi apenas escrever código HTML; foi uma verdadeira **jornada de aprendizagem prática durante o meu curso no SENAI**! O meu objetivo principal foi transformar um documento tradicional em uma **página web interativa, acessível e bem organizada**.

### 🛠️ O Passo a Passo da Construção pela Lorena Oliveira:

1. 📐 **Estruturação Semântica (HTML5):**
   - Utilizei tags semânticas modernas (`<header>`, `<nav>`, `<section>`, `<footer>`) para garantir boa acessibilidade e uma estrutura limpa.
   - Criei um menu de navegação interna com links de âncora (`#Sobre`, `#Projetos`, `#Contato`) para permitir navegar diretamente para cada seção da página.

2. 📊 **Organização de Dados & Projetos:**
   - Construí uma tabela organizada (`<table>`, `<thead>`) para listar meus projetos, as tecnologias utilizadas e o status de desenvolvimento de cada um.

3. 📝 **Formulário de Contato Dinâmico:**
   - Desenvolvi um formulário completo envolvido por `<fieldset>` e `<legend>`.
   - Incluí validação de campos obrigatórios (`required`), menu de seleção (`<select>`) e caixa de texto flexível (`<textarea>`) para receber mensagens.
